# 原生工程检查与真机测试清单

本说明基于用户上传的 AppScope.zip、hvigor.zip、entry.zip、docs.zip。上传源码保持原样；以下为静态分析，不是鸿蒙编译或真机测试结果。

## 已确认的实现

- `EntryAbility.ets` 加载 `pages/Index`，页面使用 ArkUI 与 XComponent 预览。
- `module.json5` 声明相机及陀螺仪权限；`PermissionHelper.ets` 请求相机授权。
- `YoloDetector.ets` 从 rawfile 加载 `yolov8n.ms`，使用 MindSpore Lite CPU（4 线程，FP32）推理。模型文件头为 MSL2；本环境没有执行该模型。
- 原生预处理拉伸到 640×640，将 RGB 按 NHWC 排列；解析器假设输出 `[1,84,8400]`，阈值 0.45，NMS IoU 0.45。
- `Index.ets` 以检测框位置、面积、变化及类别拼接提醒内容，陀螺仪仅辅助判定稳定性，不是图像防抖或视觉里程计。
- `SpeechManager.ets` 调用 CoreSpeechKit TTS；代码配置 `online: 1` 并注释为离线模式，是否可用需在目标 SDK/设备与语音资源上验证。没有 LLM 调用。

## 构建条件

`AppScope/`、`entry/`、`hvigor/hvigor-config.json5` 已恢复，参赛材料 ZIP 按原样保留。仓库没有命令行 Hvigor wrapper，当前云环境也没有 Hvigor、OHPM、DevEco Studio 或鸿蒙 SDK，因此未执行原生构建。项目声明目标 SDK 26.0.0、兼容 6.1.1(24)，需用支持这些配置的工具链同步。

根配置中签名列表为空却引用 default，需在 IDE 中配置本机调试签名，不能认为仓库开箱即可签名安装。保留 SDK 路径、签名私钥等本机信息在仓库之外。

## 优先处理的问题

| 位置 | 现象/风险 | 建议验证或改进 |
| --- | --- | --- |
| `Index.ets` 的时间窗口 | 检测间隔为 800 ms，而面积变化要求 `timeDiff < 800`。对同一类别每帧一个实例时，两条件基本互斥。 | 统一采样和历史窗口，使用实际时间差归一化速度；用录制序列验证靠近判定。 |
| `lastObjectState` | 按中文类别存历史，不同的人/车会共享状态，同帧多个同类也会相互覆盖。 | 引入稳定目标 ID 或位置/IoU 匹配；评测多人交叉场景。 |
| `YoloDetector.parseOutput` | NMS 不区分类别，重叠的不同类别可能互相抑制。 | 明确采用逐类 NMS 还是有意采用跨类策略，并建立目标重叠用例。Web 演示采用逐类 NMS。 |
| `preprocessImage` | 拉伸图像、NHWC 输入、假定 RGBA 数据和固定输出形状。MS 模型输入布局未在运行时验证。 | 真机打印模型输入/输出 shape、dtype；用固定图片对齐 ONNX 与 MS 输出。不要直接把 Web 的 NCHW 替换到 MS。 |
| 相机帧格式 | 预览 Profile 用于接收器输出，接收器声明 JPEG，解码又设置 NV21。是否兼容取决于设备与 API。 | 按相机支持的输出格式校验 receiver/Profile/解码方式，用真机日志确认图像成功解码。 |
| 相机生命周期 | receiverOutput 只存局部变量；释放先处理接收器再停止会话，权限申请与用户启动相机也可能并发。 | 真机验证多次开关、拒绝权限、切后台，确认输出及帧资源完整释放；明确权限完成后再启动。 |
| 设置页 | `speechSpeed`、`voiceHintEnabled`、`vibrationEnabled` 只改变 UI 状态；检测播报未读取这些值。 | 将设置接入播报控制、速度参数与振动接口，验证关闭语音后确实停止播报。 |
| 风险提示 | “远处”来自面积阈值，躲避方向来自画面左右，未使用深度或验证通行空间。 | 不应将其解释为可靠测距或安全路线；使用受控场景评测，先完善风险模型。 |
| 测试 | Hypium 测试为模板断言，没有相机或检测测试。 | 增加推理固定样本、后处理、权限拒绝、生命周期与传感器/语音用例。 |
